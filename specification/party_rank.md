# パーティランク

## 概要

パーティランクは編成時のパーティ情報から算出する.
パーティランクはHP, 攻撃, 防御, 速度の4つのステータスランクから算出する.
パーティランクは速度ランクと同じ33段階とし, `SS9`を最高, `F-`を最低とする.
実装上の列挙型は「[型定義](../design/types.md)」の`PartyRank`を使用する.

## 編成時キャラクター状態

パーティランク計算では, 戦闘中の現在HPを持つ`CharacterBattle`を使用せず, 編成時専用の`PartyCharacterStatus`を使用する.

`PartyCharacterStatus`は以下の値を保持する.

* キャラクターIDを保持する.
* 従者補正適用後の最大HPを保持する.
* 従者補正適用後の攻撃を保持する.
* 従者補正適用後の防御を保持する.
* 速度ランクを保持する.

パーティランク算出時に適用するステータス補正は従者補正のみとする.
フォーメーション, スキル, アビリティ, タクティクスによる補正はパーティランク算出へ適用しない.
アビリティおよびタクティクスの効果は戦闘中の実行時効果として扱い, 編成時のパーティランク算出値へ反映しない.

騎士団戦のパーティランクは「[騎士団戦](guild_battle.md)」編成に登録された10体全体を対象として算出する.

## ステータス集計

* HPは対象キャラクターの`PartyCharacterStatus.max_hp`を合計した総合値を使用する.
* 攻撃は対象キャラクターの`PartyCharacterStatus.attack`を合計した総合値を使用する.
* 防御は対象キャラクターの`PartyCharacterStatus.defense`を合計した総合値を使用する.
* 速度は対象キャラクターの速度レベルの平均値を使用する.
* 速度レベル平均値に小数部分がある場合は小数点以下を切り捨て, 切り捨て後の速度レベルを速度ランクへ変換する.

速度ランクは「[キャラクター](character.md#速度)」で定義する速度レベルを使用して算出する.

## パーティランク計算

```
パーティランク値 = ceil((HPランク値 + 攻撃ランク値 + 防御ランク値 + 速度ランク値) / 4)
パーティランク = パーティランク値に対応するPartyRank
```

パーティランク値の平均は小数点以下を切り上げる.
