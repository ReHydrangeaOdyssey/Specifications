# パーティランク

## 概要

パーティランクは編成時のパーティ情報から算出する.
パーティランクはHP, 攻撃, 防御, 速度の4つのステータスランクから算出する.
パーティランクは速度ランクと同じ33段階とし, `SS9`を最高, `F-`を最低とする.
実装上の列挙型は「[型定義](../../design/shared/types.md)」の`PartyRank`を使用する.

## 編成時キャラクター状態

パーティランク計算では, 戦闘中の現在HPを持つ`CharacterBattle`を使用せず, 編成時専用の`PartyCharacterStatus`を使用する.

`PartyCharacterStatus`は以下の値を保持する.

* キャラクターIDを保持する.
* 従者補正適用後の最大HPを保持する.
* 従者補正適用後の攻撃を保持する.
* 従者補正適用後の防御を保持する.
* 速度ランクを保持する.

パーティランク算出時に適用するステータス補正は従者補正のみとする.
フォーメーション, スキル, アビリティ, タクティクスによる補正はパーティランク算出へ適用しない.
アビリティおよびタクティクスの効果は戦闘中の実行時効果として扱い, 編成時のパーティランク算出値へ反映しない.

騎士団戦のパーティランクは「[騎士団戦](guild_battle.md)」編成の10スロットのうち, 有効なCharacterが登録されているスロットだけを集計対象として算出する. 未使用スロットはHP, 攻撃, 防御, 速度のいずれの集計にも含めない.

## ステータス集計

* HPは対象キャラクターの`PartyCharacterStatus.max_hp`を合計し, 小数点以下を切り捨てた整数の総合値を使用する.
* 攻撃は対象キャラクターの`PartyCharacterStatus.attack`を合計し, 小数点以下を切り捨てた整数の総合値を使用する.
* 防御は対象キャラクターの`PartyCharacterStatus.defense`を合計し, 小数点以下を切り捨てた整数の総合値を使用する.
* 速度は対象キャラクターの速度レベルの平均値を使用する.
* 速度レベル平均値に小数部分がある場合は小数点以下を切り捨て, 切り捨て後の速度レベルを速度ランクへ変換する.

## ステータスランク判定

HP, 攻撃, 防御の総合値は小数点以下を切り捨てて整数化した後, 以下の表でランクへ変換する.
F-の上限はHP`5,000`, 攻撃`1,500`, 防御`1,500`とする.
F-を0段階目とし, Fを1段階目, F+を2段階目として, 以降ランクが1段階上昇するごとに段階数を1加算する.
F-から`n`段階上のランクの増加量は以下の式で求める.

- HP: `(n * 0.1) * 10,000`
- 攻撃: `(n * 0.1) * 3,500`
- 防御: `(n * 0.1) * 3,500`

すなわち,

- HPの1段階あたりの増加量は, Fで`1,000`から始まり, 以降1段階ごとに`1,000`増加する.
- 攻撃・防御の1段階あたりの増加量は, Fで`350`から始まり, 以降1段階ごとに`350`増加する.

各ランクの上限値は, 直前ランクの上限値にそのランクの増加量を加算して求める.

速度ランクは「[キャラクター](character.md#速度)」で定義する速度レベルを使用して算出する.

## パーティランク計算

```
パーティランク値 = ceil((HPランク値 + 攻撃ランク値 + 防御ランク値 + 速度ランク値) / 4)
パーティランク = パーティランク値に対応するPartyRank
```

パーティランク値の平均は小数点以下を切り上げる.
