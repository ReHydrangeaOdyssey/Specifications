# 従者

## 概要

従者はキャラクターに編成する要素であり, 編成対象キャラクターのステータスに補正を与える.

## 編成数

* 最大2キャラクターまで編成できる.
* 同一の本体キャラクターに設定する従者の`CharacterID`は, その本体キャラクターの`CharacterID`と異なる必要がある. 本体キャラクター自身を自身の従者として設定することはできない.
* 同一の本体キャラクターに設定する2つの従者枠内では, 同一キャラクターを複数編成できない.
  - この重複禁止は本体キャラクター単位で判定し, パーティ内の別本体キャラクターに同じ従者キャラクターを設定することは制限しない.

## 制約

2枠にはそれぞれ以下の制約がある.

* スロット0には, 編成先キャラクターと同一レアリティ以下のキャラクターを編成できる.
* スロット1には, 編成先キャラクターより低いレアリティのキャラクターのみ編成できる.

## ステータス補正

* 従者の「HP」「攻撃力」「防御力」の10%が加算される.
  - 計算で使用される値はすべて32bit浮動小数点数として扱う.
    - IEEE-754規格に従う.
    - 補正後の内部値は32bit浮動小数点数のまま保持し, 戦闘計算に使用する.
    - プレイヤーから見える値のみ小数点以下をすべて切り捨てた整数として見せる.
* 従者のスキルが使用可能になる.
  - ただし「メインスキル」に設定しなければ使用されない.

### ステータス補正式

```
最終ステータス = 本体 + 従者A * 0.1 + 従者B * 0.1
```
