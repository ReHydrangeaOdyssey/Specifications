# 従者

## 概要

従者はキャラクターに編成する要素であり, 編成対象キャラクターのステータスに補正を与える

## 編成数

* 最大2キャラクターまで編成可能.
* 同一キャラクターを複数編成不可.

## 制約

2枠にはそれぞれ以下の制約がある.

* スロット0は, 編成先キャラクターと同一レアリティ以下のキャラクターを編成可能.
* スロット1は, 編成先キャラクターより低いレアリティのキャラクターのみ編成可能.

## ステータス補正

* 従者の「HP」「攻撃力」「防御力」の10%が加算される.
  - 計算で使用される値はすべて32bit浮動小数点数として扱う.
    - IEEE-754規格に従う.
    - 補正後の内部値は32bit浮動小数点数のまま保持し、戦闘計算に使用する.
    - プレイヤーから見える値のみ小数点以下を全て切り捨てた整数として見せる.
* 従者のスキルが使用可能になる.
  - ただし「メインスキル」に設定しなければ使用されない.

### ステータス補正式

```
最終ステータス = 本体 + 従者A * 0.1 + 従者B * 0.1
```
